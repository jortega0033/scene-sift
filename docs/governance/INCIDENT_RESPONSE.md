# AI Incident Response

## Trigger examples

- Unauthorized data transfer.
- Security control bypass.
- Incorrect high-impact AI output causing harmful action.
- Prompt-injection success.

## Severity levels

- Sev 1: active exploitation or broad exposure.
- Sev 2: high-risk policy/security failure with contained scope.
- Sev 3: limited-impact issue.

## Response flow

1. Contain (disable affected feature/model/prompt).
2. Preserve evidence.
3. Assess blast radius and affected users/data.
4. Remediate and validate.
5. Record post-incident actions and preventive controls.
