# SceneSift Redesign Direction

## Objective

Redesign SceneSift into a focused desktop production tool aesthetic while preserving current product truth:

- local-first project setup
- queue visibility
- system capability diagnostics
- no false implication that clipping/rendering workflows are complete

## Principles

1. Flat, monochrome interface (no gradients, glass, decorative accents).
2. Hierarchy through typography, spacing, borders, and layout density.
3. Desktop-first ergonomics for resizable windows (not mobile framing).
4. Accessibility-first semantics and keyboard operability.
5. Honest workflow framing: foundational operations only.

## Experience Targets

- Faster scanability of project/queue/status information.
- Reduced visual noise and tighter panel density.
- Consistent control height, spacing rhythm, and focus behavior.
- Stable interactions under compact windows (down to 800×700).

## Out-of-scope

- No fake clip-timeline editor or rendering workflow UI.
- No external integrations or analytics surfaces.
- No speculative AI controls that do not exist in runtime behavior.
