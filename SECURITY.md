# Security policy

## Reporting a vulnerability

Please report a vulnerability privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue, pull request or discussion for it.

Include what is affected, how to reproduce it, and the impact you expect. The owner answers on the report.

## Supported versions

Only the default branch (`main`) is supported. No release has been published yet; fixes land on `main`.
